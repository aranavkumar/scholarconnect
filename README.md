# ScholarConnect

ScholarConnect is a front-end prototype for a government scholarship portal. It guides students through login, profile verification, eligibility matching, document upload, and scholarship application.

## Features

- Mobile-number and OTP login flow
- Mock DigiLocker profile verification
- Scholarship eligibility matching using profile data
- Scholarship details, eligibility criteria, FAQs, and benefits
- Document-upload and application-progress experience
- Responsive HTML, CSS, and vanilla JavaScript interface

## Run locally

No build step is required. Clone the repository and open `index.html` in a modern browser.

```bash
git clone https://github.com/aranavkumar/scholarconnect.git
cd scholarconnect
open index.html
```

## Project structure

- `index.html` — application markup
- `style.css` — responsive styles
- `app.js` — interface state and mock scholarship data
- `logo.jpg` — application logo

## Note

This is a demonstration prototype. Its login, DigiLocker integration, scholarship records, and document handling are simulated; it is not connected to live government services.
